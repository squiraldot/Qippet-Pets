# Qippet Pets

Qippet Pets is an Android-only Flutter virtual pet companion.

## Current app

- Choose a cat, dog, or bunny from an animated picker.
- Tap the selected preview to play happy and spin animations.
- Set a local-device sleep and wake schedule.
- Persist the selected pet and schedule with the `home_widget` SharedPreferences integration.
- Placeholder geometric sprite artwork is generated until final art is ready.

The **Add to Home screen** button uses Android's native widget pin request. If the launcher cannot accept a pin request, Qippet Pets opens a step-by-step manual widget setup guide. The Settings tab also reports exact-alarm access and includes Xiaomi/Redmi/POCO MIUI and HyperOS guidance for Autostart and the **No restrictions** battery setting.

## Sprite assets

See [docs/ASSETS.md](docs/ASSETS.md) for the exact source asset contract, required canvas and transparency, frame naming, frame counts, playback rates, and Android resource synchronization steps.

- Source artwork: `assets/pets/<petId>/<state>_<nn>.png`.
- Supported pets: `cat`, `dog`, `bunny`.
- Supported states: `idle`, `tap_happy`, `tap_spin`, `sleep_start`, `sleeping`, `wake_up`.
- Keep every frame as a transparent 256 × 256 RGBA PNG, with five frames per pet/state.
- Edit source PNGs only; Android `drawable-nodpi` copies are generated by `tool/sync_pet_assets.py`.

```bash
python -m pip install Pillow
python tool/generate_placeholder_pets.py
python tool/sync_pet_assets.py
python tool/sync_pet_assets.py --check
```

The canonical art lives in `assets/pets/<petId>/<state>_<nn>.png`. Android drawable resources are generated copies; do not edit them manually.

## Development

Requirements: Flutter stable, Java 17, Android SDK API 24 or newer, Python 3.12+ and Pillow for sprite generation.

```bash
flutter pub get
flutter analyze
flutter test
flutter run
```

GitHub Actions runs `flutter analyze` and `flutter test`, then builds both debug and release APKs on every push to `main`. The release APK is published to the rolling GitHub **latest** Release.

## Download the APK

1. Open [Qippet Pets — latest Release](https://github.com/squiraldot/Qippet-Pets/releases/tag/latest).
2. Expand **Assets**.
3. Download `qippet-pets.apk` and install it on your Android device. You may need to allow installation from your browser or file manager.

The latest Release is updated by the main-branch CI workflow after both APK build variants succeed.
